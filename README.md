# Murder in the Old Villa

A first-person 3D detective game made with Unity.

The player explores an old villa, interviews suspects, collects evidence,
replays memory records, and exposes contradictions surrounding a locked-room
murder.

## Project

- Unity: `6000.5.5f1`
- Render pipeline: Universal Render Pipeline (URP)
- Primary platform: macOS
- Controls: keyboard and mouse
- Unity project folder: [`MurderInTheOldVilla`](./MurderInTheOldVilla)

See [`MurderInTheOldVilla/README.md`](./MurderInTheOldVilla/README.md) for setup and prototype
instructions.
